# TECHNOLOGY DECISIONS - MONTVERITAS

## Stack Tecnológica v1.0

- **Framework Principal**: Next.js 15+ (App Router, Server & Client Components)
- **Linguagem**: TypeScript com modo estrito e verificação rigorosa de tipos
- **Estilização**: Tailwind CSS v4 com fontes Google Playfair Display (Serif) & Plus Jakarta Sans (Sans-serif)
- **Animações**: Framer Motion (`motion/react`) para animações fluidas de scroll e transições
- **Ícones**: Lucide React
- **Roteamento SEO**: Arquivos nativos `robots.ts` e `sitemap.ts`
- **Qualidade & Linting**: ESLint + TypeScript Compiler
